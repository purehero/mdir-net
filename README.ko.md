# MDirNet

같은 공유기에 연결된 PC 끼리 파일과 폴더를 주고받는, DOS 시절 MDir 풍 터미널 프로그램.

> **MDir 과의 관계.** 화면 구성과 조작 방식(듀얼 패널, 하단 기능키 줄, 파일 보기, 마스크 선택)은 MDir 및 그 계보인 Norton Commander 관습을 따랐습니다. 다만 **MDir 자체에는 PC 간 네트워크 전송 기능이 없었습니다.** 그 시절 두 대 사이의 파일 전송은 이야기·새롬데이타맨 같은 통신 프로그램으로 ZMODEM 을 태우는 쪽이었죠. 이 도구는 MDir 의 조작 감성에 MDir 에 없던 LAN 전송을 붙인 것이고, 기능키 배치는 MDir 의 실제 키 맵이 아니라 Norton Commander 관습을 기준으로 정했습니다.

```
 MDirNet  node-alpha                                                           * node-beta 연결됨
내 PC  ~/Documents                              |node-beta  /project/src
================================================+=================================================
 ..                   [ Up-Dir ]                | ..                    [ Up-Dir ]
 FONT                 [ SubDir ] 26-07-28  3:41p| assets                [ SubDir ] 26-07-28  3:41p
*shared               [ SubDir ] 26-07-28  3:41p| README            MD       412 B 26-07-28  3:41p
 backup           SH        10 B 26-07-28  3:41p| main              PY     12.6 KB 26-07-28  3:41p
 report           TXT     2.0 KB 26-07-28  3:41p|
 song             MP3     3.3 MB 26-07-28  3:41p|
================================================+=================================================
1개 선택 . 0 B                                  |2 File  1 Dir  13,301 Byte  . 이름순
 node-beta 와 연결되었습니다
1도움    2정렬    3보기    4폴더    5복사    6이름    7만들    8삭제    9메뉴    0끝내
```

MDir 처럼 **바깥 벽이 없습니다.** 목록 위아래로 `=` 가로줄이 한 줄씩 지나고, 가운데 구분선만 세로로 하나 있습니다. 벽을 없앤 만큼 두 칸이 내용으로 돌아가고, 두 패널 모두 자기 쪽 끝에 붙어서 시작합니다. 초점이 있는 패널은 **제목 줄이 반전**됩니다.

MDir 처럼 이름과 확장자를 나누고, 폴더는 `[ SubDir ]`, 상위는 `[ Up-Dir ]` 로 표시합니다.

**확장자·크기·날짜·시간 칸은 폭이 고정**이고, **남는 자리는 이름 칸이 모두 가져갑니다.** 창을 넓히면 그만큼 긴 파일 이름이 더 보이고, 오른쪽 칸들은 늘 같은 자리에 있습니다. 크기는 `3.3 MB` 처럼 GB/MB/KB 로 보여줍니다.

창 폭이 **79칸 미만**이면 모든 칸을 담을 수 없어 시간, 날짜, 확장자 순으로 접습니다.

## 설치

Python 3.9 이상과 패키지 하나가 필요합니다.

```bash
pip install -r requirements.txt
```

전송을 TLS 로 암호화하는 데 쓰는 `cryptography` 하나뿐입니다. 파이썬 표준
라이브러리에는 인증서를 만드는 수단이 없어서 이것만 더했습니다. 나머지는
모두 표준 라이브러리입니다.

**macOS · Linux**
```bash
./run.sh
```

**Windows**
```bat
run.bat
```

런처는 자기가 놓인 폴더를 스스로 찾아 모듈 경로로 잡습니다. 어느 위치에서 호출해도 되고, 인자는 그대로 전달됩니다 (`./run.sh --name 거실PC --share ~/Downloads`).

런처 없이 직접 실행하려면 프로젝트 폴더 안에서 해야 합니다.
```bash
python3 -m mdirnet
```

양쪽 PC 에서 각각 실행하면 서로를 자동으로 찾습니다.

## 공유 폴더 목록

상대에게 열어줄 폴더를 **여러 개** 등록할 수 있습니다. 목록은 저장되어 다음 실행에도 남고, 상대에게는 **가상 루트**의 폴더들로 보입니다.

```
내가 관리하는 목록                     상대가 보는 화면
  Downloads  -> ~/Downloads          ⌜-beta  / ----------------⌝
  프로젝트    -> ~/works/proj_03      |  Downloads/            |
  사진        -> /Volumes/USB/photo   |  사진/                  |
                                     |  프로젝트/               |
                                     ⌞-3개 항목 --------------⌟
```

상대는 이 목록 위로 올라갈 수 없고, 목록에 없는 폴더는 이름으로 지정해도 거부됩니다. **내 호스트 경로는 상대에게 전달되지 않습니다** — 주고받는 경로는 `프로젝트/src/main.py` 처럼 공유 이름으로 시작하는 상대 경로뿐입니다.

### 목록 관리 (F4)

```
⌜- 공유 폴더 관리 --------------------------------⌝
| 상대에게는 이 목록이 최상위 폴더로 보입니다.    |
| ---------------------------------------------- |
|   Downloads          ~/Downloads               |
|   프로젝트            ~/works/proj_03           |
|   사진        (없음)  /Volumes/USB/photo        |
|                                                |
| ---------------------------------------------- |
| a 추가   d 삭제   Esc 닫기                      |
⌞------------------------------------------------⌟
```

- **`a`** 또는 `Insert` — 폴더 선택상자를 열어 목록에 추가합니다
- **`d`** 또는 `Delete` — 목록에서 뺍니다. **폴더와 파일은 그대로 남습니다**
- `(없음)` 은 외장 디스크를 뺀 경우입니다. 목록에는 남기고 상대에게만 감춥니다

첫 실행 때 목록이 비어 있으면 폴더 선택상자가 떠서 첫 항목을 받습니다. **폴더가 하나라도 정해지기 전에는 네트워크에 아무것도 열리지 않습니다.**

**연결 중에도 목록을 바꿀 수 있습니다.** 세션이 살아있는 목록을 보므로 추가나 제거가 상대의 다음 요청부터 곧바로 적용됩니다. 상대 화면은 다시 그릴 때까지 낡은 목록을 보여주지만, 방금 뺀 공유로 들어가려 하면 거부됩니다.

### 저장 위치

`~/.mdirnet/shares.json`

```json
[
  { "name": "Downloads", "path": "/Users/you/Downloads" }
]
```

이름은 폴더 이름에서 따고, 겹치면 `Downloads (2)` 처럼 숫자를 붙입니다.

### 인자로 지정하기

```bash
./run.sh --share ~/Downloads --share ~/works/proj_03
```

`--share` 로 준 폴더는 **이번 실행에만 적용되고 저장된 목록을 건드리지 않습니다.** 시험용이나 일회성 실행에 안전합니다.

## 쓰는 순서

1. 두 PC 에서 `./run.sh` 를 실행하고, 공유할 폴더를 등록합니다 (F4 로 더 추가할 수 있습니다).
2. 한쪽에서 **`n`** 을 눌러 발견된 PC 목록을 열고, 상대를 골라 **Enter**.
3. 상대 화면에 승인 창이 뜹니다. **Y** 로 수락, **N** 으로 거부하고, `< >` 로 골라 **Enter** 로 확정할 수도 있습니다.
4. 오른쪽 패널에 상대의 공유 폴더 목록이 보입니다. **Enter** 로 안에 들어갑니다.
5. **Tab** 으로 패널을 옮기고, **Space** 로 파일을 고른 뒤 **5** 로 반대쪽에 복사합니다.

공유 목록 자체에는 파일을 둘 수 없습니다. 복사하려면 공유 폴더 **안으로** 들어가세요.

**왼쪽 패널은 늘 내 PC** 입니다. 오른쪽은 상대 또는 **내 PC** 를 볼 수 있고 `=` 로 바꿉니다. 양쪽이 모두 내 PC 면 복사는 네트워크를 거치지 않는 로컬 복사가 됩니다. 왼쪽은 공유 폴더에 갇히지 않고 내 PC 어디든 `..` 로 올라가며 탐색할 수 있습니다. 공유로 등록한 폴더는 **상대에게 보여줄 범위**일 뿐입니다.

연결은 대칭입니다. 승인한 쪽도 상대 폴더를 그대로 탐색하고 가져올 수 있습니다.

## 상단 메뉴 (`9`, `F9`, `/`)

Norton Commander 식 풀다운 메뉴입니다. `<` `>` 로 메뉴를 옮기고 `Enter` 로 실행합니다. `9`, `F9`, `/` 중 아무거나 눌러 열고, 같은 키로 다시 닫습니다.

| 메뉴 | 담긴 것 |
|---|---|
| **Left** | 왼쪽(내 PC) 패널 설정 — 정렬, 새로고침, 폴더 트리, 드라이브 |
| **Files** | 파일 보기, 복사, 이동, 이름 바꾸기, 폴더 만들기, 삭제, 도움말, 끝내기 |
| **Commands** | 연결할 PC 찾기, 연결 끊기, 공유 폴더 관리 |
| **Options** | 숨김 파일 보기 / 감추기, 색상셋, 마우스 |
| **Right** | 오른쪽(상대) 패널 설정 — 정렬, 새로고침 |

NC 처럼 `Left` 와 `Right` 가 **각 패널을 따로** 설정합니다. 왼쪽에만 드라이브 항목이 있는데, 상대 쪽은 공유 폴더 안으로 제한되어 드라이브 개념이 없기 때문입니다.

`Right` 메뉴 맨 위에는 **내 PC 보기 / 상대 보기** 전환이 있습니다 (`=`). 오른쪽이 내 PC 를 보고 있으면 그 패널에도 드라이브 항목이 생깁니다.

**연결과 끊기는 하단 바에 없습니다.** NC 의 10칸 배치를 지키려고 `Commands` 메뉴와 문자 키(`n` / `d`)에만 두었습니다. 새로고침(`r`)과 드라이브(`\`)도 같은 이유로 `Left`/`Right` 메뉴에 있습니다. 6번은 NC 의 `RenMov` 자리이므로 이름 바꾸기입니다.

## 키 바인딩

**기능키는 하단 바에 적힌 숫자를 그대로 눌러도 됩니다.** macOS 는 F 키에 `fn` 이 필요하고 F 키의 이스케이프 시퀀스는 터미널마다 다르지만, 숫자는 어느 OS·터미널에서나 ASCII 한 바이트로 도착해 변형이 없습니다. 한글 입력 상태에도 영향받지 않습니다. (상단 숫자열만 해당합니다. 숫자 키패드는 터미널에 따라 이스케이프 시퀀스를 보냅니다.)

| 키 | 동작 |
|---|---|
| `Tab` | 패널 전환 |
| `↑` `↓` / `k` `j` | 커서 이동 |
| `PgUp` `PgDn` | 페이지 단위 이동 |
| `Home` `End` | 처음 / 끝으로 |
| `Enter` | 디렉터리 열기, 실행 파일이면 실행, 그 밖의 파일은 보기 |
| `←` / `h` | 상위 디렉터리 |
| `→` / `l` | 폴더 안으로 (파일이면 아무 일도 하지 않음) |
| `Space` | 선택 토글 (여러 개 고를 수 있음) |
| `Insert` | 선택 토글 (Space 와 같음) |
| `+` `-` | 마스크로 한꺼번에 선택 / 해제 (`*.txt`) |
| `1` / `F1` / `?` | 도움말 |
| `2` / `F2` / `s` | 정렬 바꾸기 |
| `3` / `F3` / `v` | 파일 보기 (텍스트·16진수) |
| `4` / `F4` / `o` | 공유 폴더 관리 |
| `5` / `F5` / `c` | 반대 패널로 복사 — 디렉터리는 재귀 |
| `x` | 반대 패널로 **이동** — 옮긴 뒤 원본을 지웁니다 |
| `t` | **폴더 트리** — 디스크 전체를 트리로 보고 그 자리로 옮겨갑니다 (MDir 의 MCD) |
| `Enter` (압축 파일) | **압축 안으로** — ZIP·TAR 을 폴더처럼 들어갑니다 (읽기 전용) |
| `6` / `F6` | 이름 바꾸기 |
| `7` / `F7` / `m` | 폴더 만들기 |
| `8` / `F8` / `Delete` | 삭제 (되돌릴 수 없음) |
| `9` / `F9` / `/` | 상단 메뉴 |
| `\` | 드라이브 / 볼륨 바꾸기 (내 PC 쪽만) |
| `r` | 새로고침 |
| `n` | 연결할 PC 찾기 |
| `d` | 연결 끊기 |
| `.` | 숨김 파일 보이기 / 감추기 |
| `=` | 오른쪽 패널을 내 PC / 상대 로 전환 |
| `Esc` (전송 중) | 전송 취소 |
| `Backspace` | 상위 디렉터리 (맥의 delete 키) |
| `0` / `F10` / `q` | 종료 |

숫자와 문자 키 대안이 있어 Fn 키가 막힌 터미널에서도 모든 기능을 쓸 수 있습니다. 폴더 이름이나 마스크를 입력하는 창에서는 숫자가 그대로 글자로 들어갑니다 (`2025`, `*.mp3` 처럼 칠 수 있습니다).

**한글 입력 상태에서도 단축키가 동작합니다.** 두벌식에서 `y` 를 누르면 터미널에는 `ㅛ` 가 들어오는데, 명령으로 쓰이는 자리에서는 원래 글자로 되돌려 해석합니다. 입력창에서는 되돌리지 않으므로 한글 폴더 이름을 그대로 적을 수 있습니다. 확인 창들은 `← →` 와 `Enter` 로도 고를 수 있어 입력기 상태와 무관하게 쓸 수 있습니다.

정렬은 이름 → 확장자 → 크기 → 날짜 순으로 돌아가고, 어느 기준이든 폴더가 위로 모입니다. `+` 와 `-` 는 `*.txt` 같은 패턴으로 여러 항목을 한꺼번에 고르거나 풉니다.

## Enter 로 실행하기

커서가 놓인 파일이 실행 가능하면 — POSIX 는 실행 권한(`x`), Windows 는 `PATHEXT` 확장자 — **Enter 가 그 파일을 실행합니다.** 백그라운드로 띄우고 상태줄에 남깁니다. 그 밖의 파일은 지금까지처럼 뷰어로 열립니다. F3 은 실행 파일에서도 늘 보기입니다.

입출력은 버립니다. 자식 프로세스가 우리 화면에 글자를 쓰면 TUI 가 뭉개지기 때문입니다. 부모와도 떼어놓아 MDirNet 을 끝낼 때 자식이 함께 죽지 않습니다. 원격 파일은 실행하지 않습니다 — 디렉터리 목록에 권한 정보가 없어 상대 파일이 실행 가능한지 알 방법이 없습니다. 먼저 복사해 오세요.

## 드라이브 / 볼륨

Windows 에서 `C:\` 의 부모는 자기 자신이라 `..` 으로는 **D: 에 갈 수 없습니다.** 그래서 `\` 키로 드라이브를 고릅니다.

```
⌜- 드라이브 선택 --------------------⌝
|   C:   C:\   . 고정               |
|   D:   D:\   . 이동식             |
|   Z:   Z:\   . 네트워크           |
|                                   |
| Enter 이동   Esc 취소              |
⌞-----------------------------------⌟
```

**공유 폴더 선택상자(F4)에서도** `\` 를 누르거나 최상위의 `[드라이브]` 항목을 열면 드라이브를 바꿀 수 있습니다. 이게 없으면 D: 에 있는 폴더를 공유할 방법이 없습니다.

macOS·Linux 에서는 같은 화면이 `/` 와 마운트된 볼륨(`/Volumes`, `/media`, `/mnt`)을 보여줍니다. 외장 디스크로 한 번에 건너뛰는 용도입니다.

오른쪽 패널이 상대를 보고 있을 때는 쓸 수 없습니다. 상대는 공유 폴더 안으로 제한되므로 드라이브를 옮겨가도 곧바로 거부됩니다.

## 옵션

```bash
python3 -m mdirnet --help
```

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--name` | 상대에게 보여줄 이름 | 호스트 이름 |
| `--share` | 열어줄 폴더 (여러 번 가능, 저장 안 함) | 저장된 목록을 쓴다 |
| `--root` | `--share` 하나와 같다 (호환용) | — |
| `--port` | 세션 TCP 포트 | 9600 |
| `--udp-port` | 발견용 UDP 포트 | 9601 |
| `--no-discovery` | 자동 발견을 끈다 | 꺼져 있음 |

## 화면 문자는 폭이 확정된 것만 씁니다

테두리는 모서리 `⌜⌝⌞⌟`(U+231C~231F)와 ASCII `- | =` 로 그리고, 나머지 표시는 ASCII(`~ . * o _ #`)를 씁니다. 기준은 "ASCII 인가" 가 아니라 **"폭이 확정인가"** 입니다.

`─│┌┐` 같은 박스 문자(U+2500~257F) **112자는 전부 East Asian Width 가 `A`(Ambiguous)** 입니다. 한글·CJK 환경의 터미널은 이들을 **두 칸**으로 그리는데 폭을 한 칸으로 계산하면 줄이 밀리거나 넘쳐 화면이 깨집니다. 실제로 이 한 원인에서 세 가지 증상이 나왔습니다 — 생략 표시(`…`) 때문에 줄이 1칸 밀리고, 헤더의 `·` 두 개 때문에 포트번호 2자리가 잘리고, Windows 콘솔에서 네모칸이 닫히지 않았습니다.

MDir 의 그 각진 테두리는 ASCII 가 아니라 **CP437**(IBM 확장 문자표) 상위 절반에 있던 문자였습니다. ASCII 95자에는 모서리 모양이 아예 없어 `+` 로 대신하는 수밖에 없지만, 모서리 전용 문자 `⌜⌝⌞⌟` 는 EAW 가 `N` 이라 1칸이 보장되므로 안전하게 쓸 수 있습니다.

파일 이름에 그런 문자가 들어있는 경우는 피할 수 없으므로, 폭이 애매한 문자는 **두 칸으로 계산합니다.** 넘쳐서 화면이 깨지는 것보다 빈틈이 생기는 편이 낫기 때문입니다. `tests/test_width_safety.py` 가 소스에 Ambiguous 문자가 다시 들어오지 못하게 막습니다.

## 동작 방식

- **발견** — 2초마다 UDP 브로드캐스트로 자기 존재를 알리고, 6초간 소식이 없는 상대는 목록에서 지웁니다. 알림은 **인터페이스마다 따로** 보냅니다 (아래 참고).
- **연결** — 요청을 받으면 상대 화면에 승인 창이 뜹니다. 30초 안에 승인하지 않으면 거부로 처리합니다.
- **전송** — `.part` 파일로 받은 뒤 완료 시점에 이름을 바꿉니다. 중간에 끊겨도 반쪽 파일이 남지 않습니다.

## 안드로이드

안드로이드 클라이언트는 **별도 저장소**에 있습니다. 같은 프로토콜을 쓰므로 폰도
온전한 노드입니다. 폰이 PC 를 탐색·다운로드·업로드할 수 있고, PC 도 폰에 대해 똑같이 합니다.

- 공유 폴더는 시스템 폴더 선택기(SAF)로 고릅니다. 고른 폴더만 열리고 그 밖은 닿지 않습니다.
- 앱이 화면에 없어도 PC 가 파일을 가져갈 수 있도록 포그라운드 서비스가 리스너를 유지합니다.
  앱이 앞에 없을 때는 승인을 알림으로 묻습니다.
- 두 구현의 상호 검증용 벡터는 안드로이드 저장소가 갖습니다. 규격을 고칠 때는 두 저장소를
  나란히 두고 `python3 tools/gen-golden.py --out <안드로이드>/app/src/test/resources/golden`
  으로 갱신한 뒤 양쪽 테스트를 함께 돌립니다.

두 구현이 지키는 선 위의 규격은 [PROTOCOL.md](PROTOCOL.md) 에 적어두었습니다.

## 마우스

MDir 처럼 마우스를 씁니다 (POSIX 터미널만).

- **클릭** — 그 줄로 커서를 옮깁니다. 다른 패널을 누르면 초점도 따라갑니다
- **더블클릭** — 엽니다 (`Enter` 와 같습니다)
- **휠** — 가리키는 패널의 목록이 움직입니다. 초점은 그대로입니다
- **하단 기능키 바 클릭** — 그 기능을 실행합니다

마우스를 켜면 터미널에 따라 **글자를 끌어 선택하는 것이 막힙니다.** `9` 메뉴의 `Options` 에서 끌 수 있고, 그 선택은 저장되어 다음 실행에도 남습니다.

윈도우에서는 켜지지 않습니다. 콘솔 입력을 읽는 방식이 달라 이 시퀀스가 오지 않습니다.

## 압축 파일

`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tar.xz` 를 **폴더처럼 들어가** 볼 수 있습니다 (MDir 에 있던 기능). `Enter` 로 들어가고 `..` 로 나옵니다. 안에서 `F3` 으로 파일을 보고, `5` 로 반대 패널에 꺼낼 수 있습니다.

**읽기 전용입니다.** 압축 안에 넣거나 압축 안의 것을 옮기거나 지울 수는 없습니다. 상대에게 바로 보내는 것도 안 되고, 먼저 내 PC 로 꺼내야 합니다.

MDir 이 다루던 LZH·ARJ·RAR 는 지원하지 않습니다. 표준 라이브러리로 되는 것만 다룹니다.

압축 안의 이름이 **압축 밖을 가리키면**(`../../어딘가`) 목록에서 감추고 몇 개를 감췄는지 알립니다. 그런 압축으로 목적지 밖에 파일을 쓰게 만드는 수법이 있습니다.

## 보안 범위

같은 공유기 내부를 전제로 만들었습니다. 그 선을 넘는 보호는 없습니다.

- 연결에는 **상대의 명시적 승인**이 필요합니다. PIN·비밀번호는 없습니다.
- 상대가 볼 수 있는 범위는 **등록한 공유 폴더 안쪽**입니다. 목록에 없는 이름, `../..`, 밖을 가리키는 심링크는 모두 거부합니다.
- 상대는 공유 폴더 자체를 지울 수 없습니다. 목록에서 빼는 것은 내 쪽에서만 합니다.
- **전송은 TLS 1.3 으로 암호화됩니다.** 같은 망에서 패킷을 잡아도 내용을 볼 수 없습니다. 인증서는 켤 때마다 새로 만들고 저장하지 않습니다.
- **다만 상대가 누구인지는 확인하지 않습니다.** 자기서명 인증서라 검증할 체인이 없어서, 능동적 중간자(ARP 스푸핑 등)는 막지 못합니다. 확인하려면 양쪽 화면의 **기기 지문**이 같은지 보세요. 신뢰할 수 없는 네트워크(카페·공용 와이파이)에서는 쓰지 마세요.
- **F8 삭제는 원격에도 적용됩니다.** 승인한 상대는 내 공유 폴더 **안의** 파일을 지울 수 있습니다. 공유 폴더 자체와 그 밖은 지울 수 없습니다.

## 방화벽

서로를 찾지 못하면 방화벽을 확인하세요.

- **UDP 9601** — 발견용. 막히면 `n` 목록이 비어 있습니다.
- **TCP 9600** — 세션용. 막히면 연결 요청이 실패합니다.

macOS 는 첫 실행 때 들어오는 연결을 허용할지 묻습니다. 회사망처럼 브로드캐스트가 차단된 곳에서는 자동 발견이 동작하지 않습니다.

### 포트 허용 — Windows 는 앱이 물어봅니다

Windows 에서 시작할 때 허용 규칙이 없으면 앱이 한 번 묻습니다. 동의하면 Windows 동의(UAC) 창이 뜨고, 규칙이 들어가면 다음 실행부터는 묻지 않습니다. 규칙 변경은 Windows 가 관리자 전용으로 못박아 두었으므로 동의 창 없이 조용히 여는 길은 없습니다.

`python.exe` 를 막는 **차단 규칙**이 있으면 그 목록을 보여주고 동의를 받은 뒤에만 지웁니다. Windows 는 차단 규칙을 허용 규칙보다 먼저 보므로, 이것이 남아 있으면 포트를 열어도 효과가 없습니다. 처음 실행 때 뜨는 "이 앱의 일부 기능이 차단되었습니다" 창에서 취소를 누르면 이 규칙이 만들어집니다.

### 포트를 손으로 허용하기

```powershell
# Windows — PowerShell 을 관리자로 실행
.\tools\allow-firewall.ps1          # 허용 (되돌리기: -Remove)
```

```sh
# macOS
sh tools/allow-firewall.sh          # 허용 (되돌리기: --remove)
```

Windows 쪽은 들어오는 TCP 9600~9609(세션 포트가 쓰이는 중이면 하나씩 올라갑니다)와 UDP 9601 을 **개인·도메인** 프로필에만 엽니다. 전송은 암호화되지만 상대 신원을 확인하지 않으므로 공용 네트워크 프로필은 일부러 뺐습니다.

macOS 방화벽은 포트가 아니라 실행 파일 단위로 판정하므로, 앱을 돌리는 python 실행 파일을 허용 목록에 넣습니다. 다른 python 으로 바꿔 실행하면 다시 실행하세요.

### 한쪽만 상대를 찾는 경우

발견 알림은 인터페이스마다 따로 보냅니다. `sendto("255.255.255.255")` 한 번은 라우팅 테이블이 고른 **인터페이스 하나로만** 나가고, Hyper-V·WSL·VirtualBox·VPN 어댑터가 있는 Windows PC 에서는 그 하나가 LAN 이 아닌 경우가 흔합니다. 받는 쪽은 모든 인터페이스에서 받으므로 한 방향만 되는 것처럼 보였던 원인입니다. 그래도 한쪽만 상대를 찾는다면 이 순서로 보세요.

1. **찾지 못하는 쪽의 들어오는 UDP 9601** 이 막혔는지 — Windows Defender 방화벽의 인바운드 규칙, macOS 는 시스템 설정 > 네트워크 > 방화벽.
2. **두 PC 가 같은 서브넷인지** — 게스트 와이파이나 확장기(리피터)를 거치면 브로드캐스트가 넘어오지 않는 공유기가 있습니다.
3. 상대가 보이는 쪽에서 연결을 걸면 됩니다. 연결은 대칭이라 어느 쪽이 요청해도 양쪽 모두 상대를 탐색할 수 있습니다. IP 를 직접 입력해 연결하는 길은 아직 없습니다.

## 확인된 환경

macOS(Apple Silicon, Python 3.14)에서 두 프로세스를 실제로 띄워 발견 → 승인 → 한글 이름이 섞인 중첩 디렉터리 재귀 복사까지 검증했습니다. Linux 는 같은 POSIX 경로를 쓰므로 동일하게 동작합니다.
